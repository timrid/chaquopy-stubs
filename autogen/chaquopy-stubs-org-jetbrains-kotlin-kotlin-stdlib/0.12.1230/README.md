# chaquopy-stubs-org-jetbrains-kotlin-kotlin-stdlib

Python type stubs for [`org.jetbrains.kotlin:kotlin-stdlib:0.12.1230`](https://mvnrepository.com/artifact/org.jetbrains.kotlin/kotlin-stdlib/0.12.1230), generated with [chaquopy-stubgen](https://github.com/timrid/chaquopy-stubgen) `0.3.1`.

> **⚠️ Disclaimer:** This is **not** an official tool of the [Chaquopy](https://github.com/chaquo/chaquopy) project. It is an independent, community-maintained project.

## Usage

These are stub-only packages ([PEP 561](https://peps.python.org/pep-0561/)). Install them alongside your project to get type checking support for `org.jetbrains.kotlin:kotlin-stdlib:0.12.1230` when using [Chaquopy](https://github.com/chaquo/chaquopy).

```bash
pip install chaquopy-stubs-org-jetbrains-kotlin-kotlin-stdlib~=0.12.0
```
