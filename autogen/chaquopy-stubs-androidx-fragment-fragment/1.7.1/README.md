# chaquopy-stubs-androidx-fragment-fragment

Python type stubs for [`androidx.fragment:fragment:1.7.1`](https://mvnrepository.com/artifact/androidx.fragment/fragment/1.7.1), generated with [chaquopy-stubgen](https://github.com/timrid/chaquopy-stubgen) `0.3.1`.

> **⚠️ Disclaimer:** This is **not** an official tool of the [Chaquopy](https://github.com/chaquo/chaquopy) project. It is an independent, community-maintained project.

## Usage

These are stub-only packages ([PEP 561](https://peps.python.org/pep-0561/)). Install them alongside your project to get type checking support for `androidx.fragment:fragment:1.7.1` when using [Chaquopy](https://github.com/chaquo/chaquopy).

```bash
pip install chaquopy-stubs-androidx-fragment-fragment~=1.7.0
```
